# HAUNTED STREAMER — MVP v2

> **Prototype / Internal Playtest**
> 社内プレイテスト用の試作です。ゲームバランスの検証が目的で、製品版ではありません。

夜の廃墟で配信する実況者を操作する一人称ゲーム。

## Play

インストール不要。ブラウザで開くだけで遊べます（PC + マウス推奨）。

**https://horagekai.github.io/HSProto/**

画面をクリックするとマウスが固定されて視点操作になります（`Esc` で解除）。

> URLを知っている人なら誰でも開けます。`noindex` を入れてあるので検索結果には出ませんが、
> **URLそのものは共有すれば誰にでも届く**ため、社外へ出さないでください。

## Controls

| キー | 動作 |
| --- | --- |
| `W` `A` `S` `D` | 移動 |
| マウス | 視点 ＝ そのままカメラの向き |
| `Shift` | 走る |
| `Q` | **HEY!** — 怪異へ呼びかける |
| `C` | セルフィーモード |
| `E` | 調べる / 電話に出る / 入口で配信を終える<br>（ONE GHOST MODE では**帰る専用**） |
| `F` | リクエストを断る（受諾ボタンは無い＝やれば達成） |
| `P` | デバッグパネル |
| `Esc` | マウス固定を解除 |
| `R` または `Enter` | リザルト画面でもう一度プレイ |

タイトル画面で **STANDARD MVP** / **ONE GHOST MODE** のどちらかを選びます。

## Playtest

プレイ後、**リザルト画面の `LOG (JSON)` / `LOG (CSV)` ボタン**からプレイログを保存して、
チームへ共有してください。ファイル名にモードが入ります
（例: `haunted-streamer-one_ghost-log-2026-09-04T....json`）。

ログはブラウザ内で生成してダウンロードするだけで、どこへも送信されません。

---

v1は「怪異を怒らせて逃げるゲーム」に寄りすぎていたため、v2ではループを組み替えた。

```text
廃墟に入る → 異変・撮れ高を探す → 視聴者が反応する → リクエストを受ける
  → 十分稼いだので入口へ戻る → 帰り際に高額リクエストが来る
  → 帰る or 引き返す → 欲張ったときだけ危険が上がる → 生還 / まれに死亡
```

**作りたい感情は「死ぬかどうか」ではなく「もう帰った方がいい。でも、もう一つだけ撮りたい」。**

---

## 検証モードは2つある

タイトル画面で選ぶ。バランスもログも分離してあり、片方を触ってももう片方は変わらない。

| モード | 何が怖いか | 中身 |
| --- | --- | --- |
| **STANDARD MVP** | 廃墟そのものとViewer Requestが怖い | 調査地点・環境怪異・Haunted Level・リクエスト連鎖。以下このREADMEの本文 |
| **ONE GHOST MODE** | 一体の怪異との距離感そのものが怖い | **一部屋だけ**のステージに怪異が一体。環境怪異もおつかいも無い → **[ONE_GHOST_MODE.md](ONE_GHOST_MODE.md)** |

| **HS FLOOR 1 MODE** | 本編1階のレイアウトで検証 | 仏壇・遺影・電話・風呂・冷蔵庫・ソファの人影。押しっぱなしのチキンレース → **[FLOOR1.md](FLOOR1.md)** |

世界側の恐怖と「間」を決める Pacing Director は → **[HORROR_DIRECTOR.md](HORROR_DIRECTOR.md)**

STANDARD MODE の経済（安全な反復は枯れる / 危険と新規性が儲かる）と
Request Director v2（命令ではなく誘惑）は → **[ECONOMY.md](ECONOMY.md)**

ONE GHOST MODE は初期MVPのシンプルな面白さを残すための独立モードで、
「一体の怪異だけで本当にゲームとして面白いか」だけを検証する。

## 1. 起動方法

```bash
npm install
```

```bash
npm run dev
```

表示された `http://localhost:5173`（使用中なら別ポート）をPCブラウザで開き、画面をクリックで配信開始。

```bash
npm run build
```

```bash
npm run typecheck
```

外部アセットは一切使用していません（形状はプリミティブ、音はWebAudioの合成音）。
そのため `public/` に置くモデル・テクスチャ・音声ファイルは無く、ビルド成果物は
`index.html` とハッシュ付きの JS / CSS だけです。

### デプロイ

`main` への push で GitHub Actions が `npm ci && npm run build` を実行し、
`dist/` を GitHub Pages へ公開します（[.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml)）。

Vite の `base` は `'./'`（相対パス）にしてあるので、
`https://USER.github.io/REPO/` のようなサブディレクトリ配信でもアセットが 404 になりません。
特定のパスに固定したい場合だけ `VITE_BASE` を渡してビルドします。

```bash
VITE_BASE=/HSProto/ npm run build
```

## 2. 操作方法

| キー | 動作 |
| --- | --- |
| `W` `A` `S` `D` | 移動 |
| マウス | 視点＝**配信映像そのもの**（カメラを構える操作は存在しない） |
| `Shift` | ダッシュ |
| `E` | **状況で変わる**：入口で配信終了 / 電話に出る / 調査する / 人形を持つ |
| `Q` | **HEY!**（呼びかけ）— 情報・誘導・撮れ高と引き換えに位置を知らせる |
| `C` | **Selfieモード**（カメラが自分側を向く） |
| `F` | 視聴者リクエストを**断る**（受諾ボタンは無い。やれば達成） |
| `P` | デバッグパネル |
| `R` / `Enter` | リザルトから再スタート |
| `Esc` | マウスロック解除（一時停止） |

`E` で何ができるかは画面中央にプロンプトで出ます。

**移動速度は視線と進行方向の関係で変わる**（v1から継続する中核の仕掛け）:

| 移動方向 | 速度倍率 |
| --- | --- |
| 前進 | 1.00 |
| 横移動 | 0.78 |
| 後退（＝振り返って撮りながら逃げる） | 0.55 |
| Selfie中 | さらに ×0.72 |

ダッシュ7.0 m/s に対し後ろ歩きは3.85 m/s、怪異の追跡は6.4 m/s。**撮っている間は必ず詰められます。**

## 3. テンポ設計（v2.2の中心）

このゲームの敵は「怖くないこと」ではなく **何も起きない時間**。
探索時間を増やすのではなく、**短い意思決定の回数**でプレイ時間を伸ばす。

```text
異変を発見 → 視聴者が反応 → Viewer Request → やる/やらない → 即座に結果
```

| 周期 | 起きること |
| --- | --- |
| 10〜30秒 | 異変・発見・段階報酬などの「意味のあるイベント」 |
| 15〜60秒 | プレイヤーが yes/no を突きつけられる「意思決定」 |
| 2〜3分 | 大きめのリクエスト |
| 帰り際 | Last Temptation |

**Director（[`src/systems/director.ts`](src/systems/director.ts)）** が沈黙を監視していて、
22秒なにも起きなければ強制的に異変を発生させます。リザルトの `TEMPO ANALYSIS` で実測値を確認できます。

実測（5分の探索プレイ・ボット）:

| 指標 | 実測 | 目標 |
| --- | --- | --- |
| 意味のあるイベント間隔 | 3.2秒 | 30秒以内 |
| 意思決定の間隔 | 14.9秒 | 60秒以内 |
| **最長の無イベント時間** | **10.5秒** | 30秒以内 |
| リクエスト | 8提示 / 8受諾 | — |
| 誘惑 → 引き返し | 2 → 2 | — |

### 段階的な欲張り

「見るだけ」では稼げません。同じ対象に踏み込むほど報酬が跳ねます。

```text
見つける      +100 Likes
異変が起きる  +300
触る          +1,500
一緒に自撮り  +4,000
```

### 異変 → リクエストの連鎖

異変を**目撃した2〜5秒後**に、その異変に紐づくリクエストが割り込みます。
視聴者が今の配信を見て煽っている感覚を作るための仕組みです。

| 異変 | 来るリクエスト |
| --- | --- |
| 物音 / ドアが閉まる | `CHECK THE SOUND` ¥800 |
| 人影 / 照明の明滅 | `FOLLOW IT` ¥1,200 |
| 鏡の中の何か | `LOOK INTO THE MIRROR AGAIN` ¥1,500 |
| 人形が動く | `TOUCH THE DOLL` ¥2,000 |
| 電話が鳴る | `ANSWER IT` ¥1,500 |
| **追跡開始** | **`FILM IT WHILE YOU RUN` ¥5,000** |

最後のひとつは追跡中にだけ出ます。**安全に逃げる vs 撮れ高を取る**を最大化するための煽りです。

### Hauntingによる解禁

静かな配信が、プレイヤー自身の行動で徐々に壊れていく順番を作っています。

| Haunting | 解禁される異変 |
| --- | --- |
| 0〜 | 物音 / 照明 / ドア / 人形 |
| 10〜 | 鏡 |
| 28〜 | 電話 |
| 34〜 | 廊下の人影 |

## 4. ゲームルール

### 入口＝出口

開始地点の入口が唯一の帰還地点です。自動クリア地点はありません。
入口に戻り `[E] END STREAM AND LEAVE` を押した時点で、**その時の収益が確定**します。

```text
CURRENT STREAM EARNINGS
¥18,420
[E] LEAVE AND KEEP EARNINGS
```

### 稼ぎ方

| 行動 | 効果 |
| --- | --- |
| 異変を撮る | Clip Value上昇 → Viewer/Likes/収益。**初回発見は NEW FOOTAGE ボーナス** |
| 調査地点を `E` で調べる | Likes、Haunting上昇、後で効いてくる何かが起きる |
| 視聴者リクエストを達成 | 現金報酬（¥900〜¥12,000） |
| 怪異を撮る | 高Clip Value。ただしDangerも上がる |
| 追跡中に振り返って撮る | **×4**（中央に捉えると **×6**） |
| Selfieに怪異を入れる | 距離に応じて **×1.8〜×3.5** |

同じものを撮り続けると価値が下がります（freshness）。**次の撮れ高を探す**方が儲かる設計です。

### 異変（プレイヤーを殺さないコンテンツ）

Hauntingが高いほど頻繁に起きます。

| 種類 | 内容 |
| --- | --- |
| `door_slam` | 背後でドアが閉まる |
| `light_flicker` | 照明が明滅し、廊下の奥に人影が立つ |
| `doll_moved` | 目を離した隙に人形の位置が変わる |
| `mirror_figure` | 鏡の中に自分ではないものが映る |
| `phone_ring` | 廃墟の電話が鳴る（`E`で取れる／無視もできる） |
| `noise` | 別の部屋で物が落ちる音。調べに行くか無視するか |

### 調査地点

鏡 / 人形 / 電話 / ロッカー / 古い写真 / 祭壇 の6ヶ所。近づくと `[E] INSPECT` が出ます。
調べても即座に何かが起きるとは限らず、**後から効いてくる**（人形は後で動く等）。

### 視聴者リクエスト（v2.3で構造を作り直し）

**[F] ACCEPT は廃止しました。** リクエストは投げ銭のように飛んできて、
**やれば達成・やらなければ時間切れ**。行動そのものが受諾/辞退です（`F` は「明示的に断る」に割り当て）。

表示にはリスク段階（`RISK ▁▃▅█`）とカウントダウンが出ます。

```text
💰 VIEWER REQUEST            RISK ▅
+¥4,000
GET WITHIN 5 METERS
WALK UP TO IT
[====----------]  00:24
```

#### 目的地系は「到着＝報酬」にしない

目的地へ向かうリクエストが出ると、**その場で帰路に異変が2つ仕込まれます**（照明・物音・人影など）。
そして到着しても終わりではなく、**もう一段の選択**が出ます。

```text
YOU'RE HERE — NOW WHAT?
  FILM IT              +¥1,400
  [C] SELFIE WITH IT   +¥3,100
  [E] TOUCH IT         +¥2,200
```

どれを選ぶかは**行動で示します**。ボタンはありません。何もせず立ち去れば時間切れ（＝辞退）。

#### 場所へ行かせるより、行動に制約を足す

| 種類 | 内容 | 報酬 | リスク |
| --- | --- | --- | --- |
| `TURN AROUND` | 今すぐ振り向く | ¥700 | ▁ |
| `GO BACK TO ~` | 戻って第二段階 | ¥700 | ▁ |
| `DON'T LOOK BEHIND YOU` | 20秒間、後ろを見ない | ¥2,200 | ▃ |
| `STAY WHERE YOU ARE` | 10秒間その場を動かない | ¥2,400 | ▅ |
| `KEEP IT IN FRAME` | 12秒間、目を離さない | ¥3,000 | ▃ |
| `LIGHTS OFF` | **ライトを消したまま**目的地へ | ¥5,000 | ▅ |
| `CARRY THE DOLL OUT` | 人形を抱えて入口まで運ぶ | ¥7,000 | █ |
| `TAKE A SELFIE WITH IT` | 自撮りに怪異を入れる | ¥8,000 | █ |

`DON'T LOOK BEHIND YOU` と `STAY WHERE YOU ARE` は**怪異が22m以内にいるときしか出ません**。
そうでないと「何もしないで貰える金」になってしまうためです。

#### 断ることにもコストがある

無視して時間切れになると Viewer が12%離脱し、Engagementも下がります。
一方で低報酬のリクエストは**時間コストが割に合わない**ので、断るのが正解になる場面があります。

実測の応答率（5分・ボット3種）:

| 方針 | 提示 | 応答 | 無視 | 応答率 |
| --- | --- | --- | --- | --- |
| 低リスクのみ受ける | 8 | 5 | 4 | **63%** |
| 報酬>リスクなら受ける | 4 | 2 | 0 | **50%** |
| 何でも受ける | 6 | 5 | 1 | 83% |

以前の 8/8＝100% から、方針によって割れるようになりました（目標50〜70%）。


### HEY（呼びかけ）— チキンレースの中心

`Q` で **HEY!** と叫びます。「Dangerを+25するボタン」ではありません。

| 押す理由（利益） | 押したくない理由（リスク） |
| --- | --- |
| 姿が見えないとき、**反応で位置が分かる**（`SOMETHING ANSWERED — BEHIND YOU`） | 自分の位置を知らせる |
| 声のした方へ**寄ってくる＝誘導できる**（通路を塞がれたとき等） | Danger上昇（距離が近いほど大きい） |
| 撮影中に使うと**こちらを見てくれる**＝映像価値とLikesが跳ねる | Haunting上昇 |
| 視聴者リクエストの達成手段 | 連打するほど反応が強くなる |

**反応は固定ではありません。** 距離・Haunting・連打回数（Provocation Streak）で変わります。

| 反応 | 内容 |
| --- | --- |
| `reveal` | 姿は見えないが、音で方向が分かる |
| `look` | こちらを見る（撮れ高が跳ねる） |
| `step` / `approach` | 数歩〜しっかり近づく |
| `relocate` | 別の場所へ移動する |
| `stalk` | 距離を保って付いてくるようになる |
| `lunge` | 突進フェイント |
| `rush` | 短時間の追跡（非致死） |
| `delayed` | **今は返事がない。**2〜4秒後に返ってくる（`did it hear you?`） |

Dangerの上昇は連打で `+5 → +10 → +17 → +26`（距離0.35〜2倍の補正つき）。
**「4回目で必ず追跡」のような固定パターンにはしていません。**

### チキンレース（連鎖する誘惑）

1回の遭遇の中で、報酬と危険が段階的に吊り上がります。達成すると2.5〜4.5秒後に次の段が来ます。

```text
GET CLOSER                     +¥500     （8m以内へ）
  ↓
CALL OUT TO IT                 +¥1,500   （[Q]）
  ↓
CALL IT AGAIN                  +¥4,000
  ↓
GET REALLY CLOSE AND CALL IT   +¥7,000   （5m以内で[Q]）
  ↓
TAKE A SELFIE WITH IT          +¥10,000
  ↓
DON'T TURN AROUND              +¥15,000  （Selfieのまま5秒）
```

- **報酬は達成した瞬間に確定**します。仮獲得や預け金のような会計は入れていません
- **途中で降りても、それまでの報酬は残ります**
- カードには常に `NEXT +¥4,000 — CALL IT AGAIN` と次の金額が出ます
- 毎回最後まで出るわけではなく、18%の確率で連鎖はそこで終わります
- 派生：`CALL IT WITH THE LIGHT OFF`（¥6,000）/ `CALL IT AND DON'T MOVE`（¥5,000）

**追跡中に欲張ると追いつかれます。** 撮る(+0.35)・自撮り(+0.7)・HEY(+1.6)の分だけ
怪異の追跡速度が上乗せされます（最大+1.8m/s）。撤退戦の中にもチキンレースがあります。

### ONE LAST CALL（帰り際の誘惑）

入口まで戻って `¥21,800` が確定しようとしているところに:

```text
💰 ONE LAST REQUEST            RISK ▅
+¥12,000
ONE LAST CALL
SHOUT INTO THE BUILDING  [Q]
NEXT +¥18,000 — CALL IT AGAIN
```

**戻る必要はありません。入口から中へ叫ぶだけ。** 何かが返事をします。
そして次の段が来ます。「GO BACK TO ~」のおつかいにならない誘惑です。

### 数字は見せない

**DangerとHauntingの数値はHUDに表示しません**（デバッグパネル `P` にのみ出ます）。
報酬額は正確に分かるが、危険は怪異の反応でしか分からない、という非対称にしています。

### Last Temptation（帰宅誘惑）

以下が揃うと「帰ろうとしている」と判定されます。

- すでに¥3,000以上稼いでいて、入口へ近づき続けている
- かつ **入口14m以内**（この場合は撮れ高に関係なく成立）
- または入口40m以内で、3.5秒以上まったく怪異も異変も撮っていない

このとき85%で**通常の2.2倍＋¥1,500（上限¥12,000）**の誘惑リクエストが飛んできます。

```text
💰 ONE LAST REQUEST
ONE LAST LOOK
GO BACK TO THE PHONE. ONE MORE SHOT.
+¥7,000
[F] ACCEPT  16s
```

`確実な¥18,420を持って帰る` か `戻って¥7,000を足す` か。**これがv2の中心的な判断です。**

### 危険と死（v2.3で崖をなくした）

以前は「Danger 88未満は完全に安全 / 88で突然死」でした。段階を挟んでいます。

| Danger | 起きること | 死ぬか |
| --- | --- | --- |
| 20〜40 | Observed：見られている / 覗かれる | いいえ |
| 40〜55 | Aware：距離を保ってついてくる | いいえ |
| **55〜70** | **Aggressive：突進フェイント**（3.2mで急停止する） | いいえ |
| **70〜85** | **Hunting：6〜9秒の短時間追跡。捕まっても「掴まれる」だけ** | **いいえ** |
| 85〜 | Chasing：本物の追跡 | **はい** |

**掴まれた場合**（Hunting段階）は死なずに突き放され、Dangerが52まで落ちて怪異は数秒硬直します。
Viewerは1.45倍に跳ね、コメントは荒れます。**失敗が「死」ではなく「バズる事故」になります。**

短時間追跡の間は距離によるDanger上昇を止めているので、
「怪異が寄ってきたせいで勝手に本追跡へ昇格する」ことはありません。

`Danger` は**普通に撮っているだけではほとんど上がりません**（合計0.5/秒程度）。
強く上がるのは挑発(+25) / 至近距離(2m以内で18/秒) / 危険なリクエストの達成(+14〜20) など、
**プレイヤーが自分で押した行動**です。

### 怪異の行動

追跡以外の行動を持ちます。**「怪異が動いた＝追跡開始」ではありません。**

| 行動 | 内容 |
| --- | --- |
| `idle` / `watching` | 立っている / こちらをじっと見ている |
| `stalking` | 一定距離を保って付いてくる |
| `peeking` | 出入口から半身を覗かせる。見つめると引っ込む |
| `relocating` | 画面外にいる間に別の場所へ移動する |
| `approaching` | ゆっくり近づき、5mで止まる |
| `lunging` | **突進フェイント**。3.2mで急停止して当たらない |
| `vanished` | 一定時間消える |
| `chasing` | 全力追跡 |

**追跡中以外、怪異は自分から4.5m以内には踏み込みません。**
「勝手に寄ってこられてDangerが上がった」＝ゲームに殺された、を避けるためです。

## 9. v2で検証したいこと

成功の指標は以下の発言が出ること。

- 「もう帰ろうと思ったんだけど、1万円だったから戻っちゃった」
- 「さっきの鏡に戻れって言われて嫌だった」
- 「もう十分稼いだから今回は帰った」
- 「自撮りしたかったけど怖くてやめた」
- 「欲張らなかったら生きて帰れたのに」

**「ゲームに殺された」ではなく「自分で欲張った結果、危険になった」と感じること**が最重要です。

### プレイテスト1回目で直したもの

| 症状 | 原因 |
| --- | --- |
| 調査地点の前で`E`を押しても調べられず、勝手に叫んでいた | 調査のクールダウン中に`E`が挑発へフォールスルーしていた |
| 調べても何も起きない | 調査が「後から効く」仕掛けを持っていなかった → 関連する異変を3〜11秒後に予約するようにした |
| 帰宅誘惑が一度も出ない | 帰宅判定が厳しすぎた（静物の撮れ高でリセットされていた）。入口14m以内なら無条件で成立するよう変更 |
| 「電話に出ろ」が達成不能 | 受諾しても電話が鳴っていなかった → 受けると鳴るようにした |
| 怪異がほとんど画面に出てこない（2.6%） | 消失・遠方への移動が多すぎた。一定時間見られないと近くへ寄る挙動を追加（LOS内20%まで改善） |
| Hauntingが40秒で振り切れる | 挑発・調査の上昇量が大きすぎた |
| 出入口の角で引っかかる | 経路探索が円の半径を考慮しておらず、壁際を最短経路として指していた。通路中央を優先する重み付き経路に変更し、出入口を3mへ拡張 |
| 扉が出入口を塞いで見えていた | 開いた状態の扉の角度が90°ずれていた |

### 弱くなる可能性があるポイント（v2時点）

1. **帰宅判定が緩すぎ／厳しすぎる** — 誘惑が来ないと中心的な判断が発生しない。`leaving.*` を最初に疑う
2. **リクエスト報酬がインフレしている** — Likes由来の収益(¥3/Like)が大きすぎると、リクエストの金額が霞む
3. **異変を見逃す** — 音だけの異変（noise / phone）は方向が分からないと無視される。方向表示の追加が候補
4. **怪異が見つからない／見つけすぎ** — `relocating`と`vanished`の頻度は `haunting.monsterActivity` で調整
5. **Selfieが使われない** — Selfie専用リクエストの出現率と報酬が上げどころ

## 10. 実装後のセルフレビュー

仕様書§27の要求に沿って、自分で設計を点検した結果。実測ログに基づく。

### 1. テンポが落ちている場所

| 場所 | 状況 |
| --- | --- |
| **マップ端から端への移動中** | 最北の廊下から入口まで走ると8秒。この間はほぼ確実に無イベント。Directorの閾値は22秒なので、移動が2回続くと退屈な40秒が生まれうる |
| **リクエスト達成直後の15秒** | `postCompleteCooldown` の間、視聴者が沈黙する。達成の余韻がない |
| **Haunting 100 到達後** | 異変間隔が14秒で頭打ちになり、それ以上テンポが上がらない。終盤ほど盛り上がるべきなのに平坦になる |

**改善案**：移動中専用の軽量イベント（背後で扉が鳴る・視界の端に一瞬の影・足音が二重になる）を用意し、
「走っている間」はDirectorの閾値を12秒へ下げる。
達成直後は必ず視聴者の反応（Viewer急増＋専用コメント）を1つ挟む。
Haunting 90以上では「怪異が能動的にプレイヤーの前へ回り込む」演出を解禁する。

### 2. 意思決定がないイベント

| イベント | 問題 |
| --- | --- |
| `door_slam` / `noise` | リクエストのスロットが埋まっていると「音がした」で終わる。見るだけになる |
| `light_flicker` | 人影の表示が9秒と短く、気づかないまま消えることがある |
| 調査地点の初回発見 | `+100 Likes` が入るだけで、その場の選択がない |

**改善案**：リクエストスロットを2つにする（大きいもの1つ＋軽量なもの1つ）。
軽量リクエストは報酬¥500以下・制限20秒の「その場で答える」枠にする。
初回発見時に「近づいて調べる？」の簡易プロンプトを出し、無視も選べるようにする。

### 3. 同じ行動を繰り返している場所

- **調査地点でのEの連打**：ボットは5分で32回`inspect`した。2回目以降も25%のLikesが入るため、単純作業で稼げてしまう。
  → **改善案**：2回目以降の報酬を0にし、代わりに「もう見た」系のコメントを返す。報酬は段階（触る/自撮り）へ移す。
- **怪異を遠くから撮り続ける**：freshnessの下限が0.25あるため、放置でも少額が入り続ける。
  → **改善案**：同一被写体を20秒以上撮り続けたら下限を0にし、コメントを「飽きた」系へ切り替える。

### 4. Viewer Requestがクエスト化している場所

- **`GO BACK TO ~` 系がおつかい化**している。目的地へ歩くだけで、道中に何も起きない。
  → **改善案**：`go_back`を受諾した瞬間に、その地点で新しい異変を予約する。
  **到着＝報酬ではなく、到着＝新しいイベント**にする。これが今回いちばん効く改善だと考える。
- **`check_sound` / `follow_it` も同型**。行って終わり。
  → **改善案**：到着時に低確率で「そこには何もない」→直後に背後で異変、という空振り演出を入れる。
- リクエストの受諾率が8/8（実測）と高すぎる。**断る理由がない**＝意思決定になっていない。
  → **改善案**：断ると視聴者が減る（Engagement低下）ペナルティを付け、
  「受ける／断る」の両方にコストを持たせる。

### 5. Chaseが強すぎる / 弱すぎる場所

- **Danger 88 の一点だけが崖**になっている。87までは完全に安全、88で急に致命的。段階が体感できない。
  → **改善案**：Aggressive（65〜）で「一度だけ突進して途中で止まる」フェイントを入れ、
  追跡が来る予感を体で分からせる。
- **追跡の距離管理が弱い**：ダッシュ7.0 vs 追跡6.4で、振り返らなければほぼ確実に逃げ切れる。
  緊張はあるが、失敗しない。
  → **改善案**：追跡が10秒を超えたら怪異を加速させる（6.4 → 7.2）。
  「早く出口へ行くか、撮ってから行くか」の判断に締切を作る。
- 逆に、**追跡中の`FILM IT WHILE YOU RUN`（¥5,000）は強すぎる可能性**がある。
  2秒フレームに収めるだけで、通常リクエスト3件分。実プレイのログで達成率を見て調整する。

### 総括

いま最も弱いのは **4番（リクエストのおつかい化）** だと考える。
「異変 → 反応 → リクエスト → 即座に結果」の最後の「即座に結果」が、
`go_back`系では「歩く」に置き換わっている。
次の改修では、**リクエストの目的地に着いた瞬間に必ず何かが起きる**ようにするのが最優先。
